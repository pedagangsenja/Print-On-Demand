## Dapatan

1. **Saiz teras:** 16×20, 18×24, 24×36 (+ 8×10/11×14 untuk set). Printify: 18×24 pilihan ramai, 24×36 perlu harga premium; tawarkan beberapa saiz sahaja.
2. **Untung dolar tertinggi:** canvas ($46–63) dan set berbingkai ($57). Berbingkai asas $13.19 memberi untung ~$33 pada $49.99 (kualiti bingkai perlu disahkan dengan sampel).
3. **Set kelas fizikal (12 poster) untung rendah ($26, 26%)**: jual sebagai **bundle digital** ($23.3, 93%) atau set fizikal kecil.
4. **Bilik lembap:** gunakan metal sign atau berbingkai, bukan kertas biasa.
5. Penanda aras harga POD: $28–55 / $32–65 / $45–85 untuk saiz popular; digital $12–18 lazim.
