      Siapa pembeli dan bagaimana mereka membeli?

      "Bulk" bermaksud satu pesanan untuk ramai orang (contohnya set bridal 4–8 helai); "satu-satu" bermaksud satu item setiap pesanan.

      Bila nak pin dan jual?

      Warna lebih pekat = bulan jualan lebih tinggi (100 = bulan biasa). Mula pin 45–90 hari sebelum bulan puncak.
