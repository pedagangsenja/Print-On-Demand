Hierarki 3 lapis

Baris melengkung kecil, tajuk besar, reben. Mata baca dari atas ke bawah dalam 1–2 saat. Tajuk mesti 2 hingga 4 perkataan.

pendapat · amalan biasa

Warna ikut mood

Hitam/emas = cita-cita dan mewah. Merah hati = semangat dan gym. Biru malam = fokus dan pagi. Hijau = tenang dan tumbuh. Krim = vintage cerah untuk suapan yang terang.

lemah · psikologi warna tiada bukti kukuh

Kontras walaupun berhias

Garis luar gelap dan bayang 3D memisahkan huruf dari latar. Warna emas utama dikira kontras WCAG terhadap latar.

Halaman ini untuk pratonton sahaja. PNG untuk dimuat naik ke Printful/Gelato dijana di komputer dengan skrip repo:

node scripts/ornate_export.js --size pin     # 1000×1500, untuk pin
node scripts/ornate_export.js --size print   # 3600×5400 = 24×36 in pada 150 dpi
node scripts/ornate_export.js --spec saya.json   # poster sendiri (senarai spesifikasi)
